# Sellora for Android

The Sellora app for store owners and staff. See today's orders, update order
status, read and reply to WhatsApp chats, switch products on or off, and get
notified about new orders, low stock and billing.

## Download

**[⬇ Download the latest APK](https://github.com/nadun-dilshan/sellora-releases/releases/latest/download/sellora-android.apk)**

Requires Android 7.0 or newer. Not available for iPhone yet - use the web
dashboard at https://app.sellora.nadun.me in Safari.

## Install

1. Open the download link on your Android phone.
2. If Android asks, allow your browser to install apps ("Install unknown
   apps"). This is only needed once.
3. Open the downloaded file and tap **Install**.
4. Google Play Protect may warn that the app is not from the Play Store.
   Choose **Install anyway** - the app is published directly by Sellora.
5. Open Sellora and sign in with the same email and password you use on the
   web dashboard. Staff accounts work too.

Turn on notifications when the app asks. You can change this later in the
**More** tab.

## Updates

The app updates itself. Most changes arrive automatically the next time you
open it. Occasionally a new version needs a fresh install - the app will tell
you, and the download link above always points to the newest one.
